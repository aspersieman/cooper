# cooper
Single file, zero dependency home page for your browser

## Use case

 1. You want to store some bookmarks locally on a particular browser and, for whatever reason, don't want to use your browser's bookmarks feature
 2. You want a simple/basic home page for your browser

## Usage

Clone download the `home.html` file. Go to your browser's settings and set it as your home page.

## Note

 - Cooper only stores data locally on your machine in the relevant browser's local storage
